# PB&RN Digital Compass

Crie uma aplicação web responsiva, moderna e premium no estilo landing page interativa + checklist estratégico, para a PB & RN Foods, com foco no projeto de transformação da Plataforma Digital B2B.

A aplicação será utilizada pela direção e equipe do projeto para acompanhar visualmente a evolução das ações estratégicas. O resultado precisa transmitir tecnologia, distribuição, inteligência comercial, crescimento e profissionalismo, sem parecer um sistema administrativo pesado.

IDENTIDADE VISUAL

Utilize como referência principal a logomarca original PB & RN Foods anexada ao projeto.

Regras obrigatórias:

utilizar a logomarca original sem redesenhar;

não alterar proporções;

não modificar suas cores;

não recriar o símbolo;

aplicar a logo com excelente legibilidade;

branding principal em preto, vermelho, branco e tons de cinza/grafite;

vermelho deve funcionar como cor de ação e destaque;

fundo predominantemente claro;

blocos escuros podem ser utilizados estrategicamente para criar contraste;

visual institucional, comercial, tecnológico e premium;

evitar excesso de ícones;

evitar aparência genérica de template SaaS;

evitar excesso de gradientes;

usar bastante espaço em branco;

bordas arredondadas modernas;

sombras leves;

microinterações discretas;

tipografia moderna, forte e extremamente legível.

Referência de sensação visual:

Brandbook moderno + dashboard executivo + landing page estratégica B2B.

Criar um checklist visual para acompanhar a transformação do atual e-commerce em uma verdadeira:

PLATAFORMA DIGITAL B2B

FUNCIONALIDADES DO CHECKLIST

Todos os itens devem possuir checkbox interativo.

Quando um item for concluído:

checkbox assume vermelho da marca;

card ou linha recebe estado de concluído;

texto pode receber leve alteração visual;

atualizar automaticamente o percentual geral.

Calcular:

itens concluídos / total de itens × 100

Mostrar o resultado no Hero.

Exemplo:

Progresso da Transformação: 37%

Criar barra de progresso animada.

A PB & RN Foods é a marca principal da aplicação.

Use a logomarca original fornecida como ativo real do projeto.

Não recrie ou substitua a logomarca por texto genérico, ícones ou monogramas.

preto + vermelho + branco + grafite

com estética institucional, tecnológica, comercial e premium.

O resultado deve parecer uma solução desenvolvida especificamente para a PB & RN Foods, e não um template reaproveitado.
